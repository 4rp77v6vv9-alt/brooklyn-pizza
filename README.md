# Бруклинская пицца — Android App

Тестовый Android-клиент для первого запуска приложения на реальном телефоне.

- package: `ru.brooklynpizza.magnitogorsk`
- сервер: `https://brooklyn-pizza-chennchef.amvera.io`
- min Android: 7.0 (API 24)
- target SDK: 36

GitHub Actions автоматически собирает тестовый APK. После успешной сборки артефакт называется `Brooklyn-Pizza-APK`.

Это тестовая версия. Перед публикацией в Google Play будут добавлены release-подпись, AAB, полноценные push/deep links и финальная проверка оплаты.
